# ESPHome YAML 生成器

一个用于生成 ESPHome YAML 配置的 Web 工具。

## 功能
- 通过 Web 界面生成 ESPHome YAML 配置
- 支持常见 ESPHome 组件
- 实时预览生成的配置

## 安装
1. 在 Home Assistant 中添加仓库：`https://github.com/txhtxh11/ha-addon-repo`
2. 在插件商店中找到 "ESPHome YAML 生成器"
3. 点击安装并启动

## 配置
无需额外配置，安装后即可使用。

## 访问
- Web 界面：`http://你的HA地址:8080`
- 或通过 Home Assistant 侧边栏入口
